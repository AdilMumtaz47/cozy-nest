# Cozy Nest — Home Decor Blog (Pinterest pipeline)

Static website for the Pinterest → blog workflow. No database, no CMS, no admin
dashboard. Articles are Markdown files; this repo builds plain HTML pages from
them. Hosting: Vercel (auto-deploy on push to `main`).

## How to publish a new article

1. Write the article file in `content/posts/<slug>.md` (copy
   `content/posts/_template.md`).
2. Add its images to `images/<slug>/` — portrait JPGs, each under 100 KB,
   named by what they show (kebab-case), one image per design, in order.
3. Run `python3 build.py` — it regenerates `index.html`, `posts/<slug>/`,
   `sitemap.xml` and `robots.txt`.
4. Commit everything (Markdown + images + generated HTML) and push to `main`.
   Vercel deploys automatically.
5. Open the live article page and verify: title count == design count ==
   image count, all images loading in order with the right alt texts, FAQ
   section present. Only then is the article "published complete".

## Layout

- `content/posts/` — article Markdown files (frontmatter: title, slug,
  description, keyword, category, date, images with file + alt).
- `images/<slug>/` — article images for that slug.
- `images/pins/` — pin images `<slug>-pin1.png`, `-pin2.png`, `-pin3.png`.
- `posts/<slug>/index.html` — generated article pages (do not edit by hand).
- `index.html`, `sitemap.xml`, `robots.txt` — generated by `build.py`.
- `pinterest-master-record.md` — the master record: keywords, articles,
  boards, pins, performance. Check it before every new keyword.
- `keyword-screen-1.md` — first keyword screening batch.

## Rules that never change

- Article images are real photos sourced from Instagram/web search — never
  AI-generated. Every image checked full-frame AND the bottom 35% strip for
  watermarks. Watermarked / cut-off / off-topic = unusable.
- Counts are always the TRUE count (images actually present) — never a fixed
  number. Title count == design count == image count == meta count.
- No invented statistics, no fake reviews, no backdating.
- No pins without a published, live-verified article.
- Never ask for or store passwords, codes or secrets in this repo.
