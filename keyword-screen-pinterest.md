## Method (applied identically to all 40 phrases)

- **Autocomplete check:** typed the exact candidate phrase into the Pinterest search box. "Exact in autocomplete = YES" means the dropdown contained a suggestion exactly equal to that phrase. Typing a shorter stem and seeing a longer suggestion does NOT count — e.g. "christmas dining room decor ideas" appears when typing "christmas dining room", but typing the full phrase does not return it verbatim, so it is NO.
- **Listicle count:** first 12 pin cards in Pinterest's own order for that exact search. A pin counts as a listicle when its heading (or link/alt text where it has no heading) contains a number introducing a list (e.g. 15, 20+, 37, "6 Steps"). Years (2026/2027), prices and sizes not counted. Bands: 0–3 = STRONG, 4–6 = WINNABLE, 7+ = REJECT. A phrase appearing verbatim in autocomplete is REJECT regardless of count.
- **Click-fit:** only broad room / season / use-case clusters pass; a single tiny item or off-topic results fail.
