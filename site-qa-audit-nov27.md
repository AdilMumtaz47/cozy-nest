## MUST-FIX

### 1. Dead internal link — neutral-bedroom → cozy-winter-bedroom-ideas (404 live)
- **Location:** `content/posts/neutral-bedroom.md` L75 (intro) and L261 (Takeaway bullet); rendered at https://www.cozynesthomeideas.com/posts/neutral-bedroom/ (both links present in the live HTML).
- **Evidence:** the link text reads "…and [30 Cozy Winter Bedroom Ideas for a Warm Retreat](/posts/cozy-winter-bedroom-ideas/) shows the seasonal version." The slug `cozy-winter-bedroom-ideas` does not exist among the 62 articles — it exists only as the draft `_template.md`. Live check: https://www.cozynesthomeideas.com/posts/cozy-winter-bedroom-ideas/ returns **404**. It is the ONLY dead `/posts/` target site-wide (63 distinct rendered targets checked; all others resolve).
- **Fix:** either publish the cozy-winter-bedroom-ideas article (the template draft already exists for that slug) or replace both links with an existing article (e.g. `christmas-bedroom` or `winter-home`).

### 2. Sitemap host ≠ canonical host — all 79 URLs
- **Location:** `sitemap.xml` (generated by `build.py`); also `robots.txt`.
- **Evidence:** every `<loc>` uses `https://cozynesthomeideas.com/…` (non-www); zero use `https://www.`. The live canonical is `https://www.cozynesthomeideas.com/` — the non-www homepage returns **308 → https://www.cozynesthomeideas.com/**, and all 79 sitemap URLs return 308 raw / 200 after following the redirect. `robots.txt` also lists `Sitemap: https://cozynesthomeideas.com/sitemap.xml` (non-www). Independently re-verified: `grep -o "<loc>"` = 79; `grep -c "https://www.cozynesthomeideas.com"` in the sitemap = 0.
- **Fix:** regenerate the sitemap (and the `robots.txt` sitemap line) with the www host. Impact is crawl/canonical consistency, not visitor breakage — all 79 URLs end at 200.

### 3. Footer social icons mislabelled / mislinked — Facebook, X, Instagram all go to Pinterest
- **Location:** homepage footer (every page — the footer is shared), `.footer-social` in `styles.css` / `build.py` footer template.
- **Evidence:** the footer has 4 social anchors; three carry the titles **"Facebook"**, **"X"** and **"Instagram"** with their brand SVG icons, but all three link to `https://www.pinterest.com/cozynestbysayed/`. Only the fourth ("Follow on Pinterest") is labelled correctly. Clicking the Facebook icon takes the visitor to Pinterest, not Facebook.
- **Fix:** remove the Facebook / X / Instagram icons (no such profiles exist — this was a known placeholder from Nov 24: "Footer social icons link to Pinterest profile for now (no FB/X/IG yet)"), keeping only the correctly-labelled Pinterest link; or point them at real profiles if those exist.

### 4. Featured hero still shows 2027-christmas, not the seasonal pick (verify after the in-flight push)

- **Evidence:** live homepage at 14:33 PKT still features `/posts/2027-christmas-decor-ideas/` ("30 2027 Christmas Decor Ideas for a Festive Home"). `build.py` L23 already has `FEATURED_SLUG = "cozy-christmas"` and the locally built `index.html` already features `posts/cozy-christmas` first — the change is built but **not yet pushed live** at audit time (the image coordinator's push was still in flight).
